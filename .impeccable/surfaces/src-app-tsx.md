# Bridge workspace

Mode: Operate. Owner task: find a bot, write a message, verify the reply; create a bot or search private history without losing the current draft.

## Direction contract

THESIS: A private conversation desk, not a developer dashboard. Bots own the sidebar; one task owns the canvas.

OWN-WORLD: Charcoal surfaces, off-white system sans, pink primary action, muted olive/amber status. Rounded controls, quiet separators, compact avatars. No glow, gradients, or decorative metrics.

STORY: Sign in, pick or create a bot, compose, verify. Offline means unavailable—not an empty roster or failed sign-in.

FIRST VIEWPORT: Full-height 272px sidebar; 64px toolbar; centered conversation or focused form; anchored composer. New bot is always findable. Mobile folds the sidebar into a keyboard-accessible drawer. Signature interaction: draft-preserving bot switching; 180ms drawer reveal only.

FORM: User-pinned dark sidebar chat screenshot overrides seed 7cff262a. Code-led, approved in chat; no comp.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
